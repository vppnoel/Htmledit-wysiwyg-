📝 Éditeur HTML WYSIWYG

Éditeur personnalisé - Collez votre texte, éditez-le visuellement, et récupérez le code HTML

Mode actuel: ✏️ Édition visuelle

💡 Instructions d'utilisation

  • Coller du texte: Collez directement votre texte depuis Word ou tout autre éditeur
  • Éditer: Utilisez la barre d'outils pour formater votre texte (gras, italique, listes, etc.)
  • Voir le code: Cliquez sur "Voir le code source" pour afficher le HTML généré
  • Copier le HTML: Utilisez le bouton "Copier HTML" pour copier le code dans le presse-papiers
  • Modifier le HTML: En mode source, vous pouvez modifier directement le HTML et revenir en mode visuel
