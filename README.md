# Éditeur HTML WYSIWYG

Un éditeur HTML WYSIWYG (What You See Is What You Get) simple et efficace, développé en JavaScript.

## 🎯 Fonctionnalités

- **Édition visuelle** : Interface intuitive pour éditer du texte formaté
- **Collage depuis Word** : Collez directement du contenu depuis Microsoft Word
- **Vue du code source** : Visualisez et modifiez le code HTML généré
- **Barre d'outils complète** : Formatage de texte (gras, italique, souligné, listes, etc.)
- **Copie du HTML** : Copiez facilement le code HTML dans le presse-papiers
- **Interface responsive** : Fonctionne sur desktop et mobile

## 🚀 Utilisation

1. Ouvrez le fichier `index.html` dans votre navigateur web
2. Collez ou tapez votre texte dans l'éditeur
3. Utilisez la barre d'outils pour formater votre texte
4. Cliquez sur "Voir le code source" pour afficher le HTML généré
5. Utilisez "Copier HTML" pour copier le code dans le presse-papiers

## 💻 Technologie

- HTML5
- CSS3
- JavaScript (Vanilla)
- Native browser contentEditable API for rich text editing

## 📦 Déploiement

Aucune installation requise ! Cet éditeur fonctionne entièrement côté client.
Il suffit d'ouvrir le fichier `index.html` dans un navigateur moderne.

Pour le publier en ligne :
- Hébergez le fichier sur GitHub Pages, Netlify, Vercel, ou tout autre service d'hébergement statique
- Aucune configuration serveur nécessaire

## 🌐 Démo en ligne

Pour utiliser cet éditeur en ligne, hébergez simplement le fichier `index.html` sur votre service préféré.
