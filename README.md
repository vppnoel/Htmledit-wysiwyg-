# Éditeur HTML WYSIWYG

Deux éditeurs HTML WYSIWYG (What You See Is What You Get) puissants, développés en JavaScript.

## 🎯 Deux options disponibles

### 1. Éditeur Personnalisé (Léger & Rapide)
Un éditeur simple et efficace, parfait pour une utilisation rapide sans dépendances externes.

**Fonctionnalités:**
- Interface intuitive et épurée
- Aucune dépendance externe
- Chargement ultra-rapide
- Formatage de texte essentiel (gras, italique, listes, etc.)
- Vue code source intégrée
- Copie HTML en un clic

### 2. TinyMCE (Professionnel)
L'éditeur WYSIWYG le plus populaire au monde, avec des fonctionnalités avancées et professionnelles.

**Fonctionnalités:**
- Interface professionnelle complète
- Plugins et extensions riches
- Support avancé du formatage
- Insertion d'images et médias
- Tableaux et mises en page complexes
- Rechercher/Remplacer intégré

## 🚀 Utilisation

1. Ouvrez le fichier `index.html` dans votre navigateur web
2. Choisissez l'éditeur qui correspond à vos besoins
3. Collez ou tapez votre texte dans l'éditeur
4. Utilisez la barre d'outils pour formater votre texte
5. Cliquez sur "Voir le code source" pour afficher le HTML généré
6. Utilisez "Copier HTML" pour copier le code dans le presse-papiers

## 💻 Technologie

### Éditeur Personnalisé
- HTML5
- CSS3
- JavaScript (Vanilla)
- Native browser contentEditable API

### Éditeur TinyMCE
- HTML5
- CSS3
- JavaScript
- TinyMCE 8.3.2 (version libre)

## 📦 Déploiement

Aucune installation requise ! Cet éditeur fonctionne entièrement côté client.
Il suffit d'ouvrir le fichier `index.html` dans un navigateur moderne.

Pour le publier en ligne :
- Hébergez le fichier sur GitHub Pages, Netlify, Vercel, ou tout autre service d'hébergement statique
- Aucune configuration serveur nécessaire

## 🌐 Démo en ligne

Pour utiliser cet éditeur en ligne, hébergez simplement le fichier `index.html` sur votre service préféré.
